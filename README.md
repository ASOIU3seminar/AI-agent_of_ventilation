# AI Agent of Ventilation 🌬️

Автоматизированная система (ИИ-агент) для расчета нормативного воздухообмена и автоматической генерации Характеристик отопительно-вентиляционных систем (ХОВС) по ГОСТ 21.602. 

Система принимает на вход архитектурные чертежи (САПР) и таблицы с атрибутами помещений, сводит их в единую графовую модель, применяет математические алгоритмы по СП 60.13330.2020 и выгружает готовую рабочую документацию в Excel.

## 🚀 Функционал
- **CAD Extractor:** Извлечение геометрии, контуров помещений, высот и площадей из форматов DWG/IFC.
- **Data Mapper:** Умное сопоставление извлеченной геометрии с атрибутикой помещений из входных пользовательских XLSX-таблиц.
- **HVAC Engine:** Мультиагентный расчет воздухообмена (по кратности, количеству людей, теплоизбыткам) и сведение воздушного баланса здания.
- **Excel Generator:** Формирование итогового отчета ХОВС с применением стилей, формул и шаблонов, регламентированных ГОСТ.

## 🛠 Стек технологий
- **Backend:** C# (.NET 8) — ядро математических расчетов и бизнес-логики.
- **Frontend:** React — пользовательский интерфейс для загрузки исходников и выгрузки результатов.
- **База данных:** GRAFDB (MetagraphFramework) — графовая СУБД для хранения топологии помещений, связей систем вентиляции (П1, В1) и направлений перетоков воздуха.
- **Работа с документами:** OpenXML (генерация Excel), CAD API.
- **Инфраструктура:** Docker, Docker Compose.

## ⚙️ Установка и запуск (Локально)

Требования
    .NET 8 SDK

    Node.js (для фронтенда)

    Docker Desktop

# Шаги по запуску
Клонируйте репозиторий:

```Bash
git clone [https://github.com/ASOIU3seminar/AI-agent_of_ventilation.git](https://github.com/ASOIU3seminar/AI-agent_of_ventilation.git)
cd AI-agent_of_ventilation
```
# Соберите и запустите сервисы через Docker:

```Bash
docker-compose -f infrastructure/docker-compose.yml up -d --build
```
# Для локальной разработки бэкенда:

```Bash
dotnet restore hvac-auto-calculator.sln
dotnet build
dotnet run --project src/HVACCalculator
```

## 📄 Нормативная база 
СП 60.13330.2020 (Отопление, вентиляция и кондиционирование воздуха)

ГОСТ 21.602-2016 (Правила выполнения рабочей документации отопления, вентиляции и кондиционирования)
